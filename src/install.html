On school PCs: as a bookmark

  1. Show the bookmarks bar: Ctrl + Shift + B
  2. Drag this button onto the bookmarks bar: PP Helper
  3. Log in to the portal, then click the bookmark once. After reloading the page (F5), click it once more.

On your own PC: automatically with Tampermonkey

  1. Install the Tampermonkey browser extension (available for Chrome, Edge and Firefox).
  2. Chrome/Edge only: right-click the Tampermonkey icon → “Manage extension” → turn on “Allow User Scripts”.
  3. Tampermonkey icon → “Create a new script” → delete everything in the editor → paste the script below → Ctrl + S.

How to use it

  • Today / Now: A button appears next to date and time fields. One click fills in today’s date or the current time.
  • Link fields: Click “Helper” in the bottom right → “+ Link fields” → first click the field to copy from, then the target field. From then on, whatever you type into the first field also appears in the second.
  • You can still change the target field yourself: your value then stays (orange marker). If you clear it, it is filled automatically again (blue marker).
  • Links are saved per browser. “Export” gives you a code that you paste under “Import” in the helper on another PC.

Note: Only use it during exams in the portal if your teacher allows it.
